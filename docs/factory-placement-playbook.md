# Garment placement playbook (MD-Brain 1.4)

The owner's seven placement rules are installed as locked Brain records by an idempotent migration. The 21 supplier product guides are maintained in `request-service/factory-placement-playbook.mjs` and shown in AI Intelligence with their mapped current catalog listings. Existing products and owner memories are preserved.

The exact product guide accompanies workflow briefs, AI layout planning and saved-mockup review. The old mandatory hoodie-pocket continuation rule is replaced with a black-pocket default. A structural panel cannot silently borrow unrelated artwork. Instructions do not establish visual completion: missing mockup views stay unreviewed.

## Enforced production checks

Unclassified sources default to hero. Basic provides hero, motif, strip, pattern and composed-panel controls. Repetition requires an explicit owner approval tied to the source ID and checksum, plus Crop permission for bleed. A model's classification cannot grant approval. Rendering checks this before producing or reusing files, and technical quality checks it again before publication. Revoking approval blocks cached tiled recipes. Two heroes cannot occupy the same intended safe region; independently reviewed leg regions may share a native print panel.

This does not detect repetition already baked into uploaded pixels. Existing published images are not regenerated. Visual quality still requires actual mockup review, and semantic AI analysis requires the configured provider. No provider, budget, authentication or publishing-mode settings are changed by this update.

## Reusable Basic profiles

Choose a numeric layout, assign artwork roles and panels, inspect sizes and coordinates, and accept any reductions. Save this layout profile, or create the inspected item to save it automatically. Profiles are keyed by supplier product, printing method, layout and audience, with a fingerprint of selected variants and exact native templates. The saved record retains artwork IDs/checksums, coordinates, safe rectangles and source measurements.

Basic reloads compatible profiles. Different sizes/templates require reinspection. Switching design sets retains compatible part names and geometry, but requires explicit repeat approval again when loading a saved profile and never carries that approval to a new set; missing source parts remain unassigned. A saved profile never authorizes creation without a fresh inspection receipt. Anatomical safe regions still require a reviewed product-specific guideline; the playbook does not invent coordinates from generic garment names.

Owner review remains required. This release does not approve, publish, delete or rewrite any real product.
