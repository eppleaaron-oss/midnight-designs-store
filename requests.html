Requests.

This owner workspace stores records only in this browser. Import customer request files or add emailed requests manually. Automatic intake, shared storage, payments and fulfillment are not connected. Export backups regularly and use your own device.

How requests arrive

Custom artwork customers can download a request file and email it with references. Create yours customers can email their full design file. Import either file here, or add an email, question or revision manually. Keep original artwork files in your private storage; this queue records their filenames and the brief.
