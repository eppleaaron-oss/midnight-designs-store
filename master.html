AI design desk

Generate clothing artwork and upload it into your Printful file library through the protected owner workflow. Setup required: OPENAI_API_KEY with API billing and PRINTFUL_TOKEN with file-upload access.

1. Choose artwork pictures

Generate artwork + send to Printful ↗Configure connections ↗

Select Run workflow on GitHub. Enter your design name, description, and placement. Paste the copied reference IDs and garment map JSON into their matching workflow fields. Leave Send to Printful checked to upload the image. Each generation uses your paid image API. You can see progress and errors in that workflow.

Generated artwork appears in the Designs gallery. In Printful, apply the uploaded image to a garment and review the print area, resolution, sizes, and mockups before publishing. This does not create orders or automatically publish a garment.
